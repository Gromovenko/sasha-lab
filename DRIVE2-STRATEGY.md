# Стратегия по Drive2 (черновик от 19.09.2026)

Готовится, пока идёт основной харвест. Цель — взять у Drive2 только то, что
продолжает уже собранную тему, а не «всё про машины».

## 1. Тема: что считается «в рамках»

Собранный корпус (20+ сайтов, 783+ fitment-фактов) — это ретрофит фар:
- **посадка**: какая линза/модуль встала в какую фару какой машины (марка, модель, год, поколение);
- **комплектующие**: bi-LED / bi-xenon линзы (Aozoom, Optima, MTF, Zorkiy, Luxsar…), блоки розжига, маски, стёкла, диаметры;
- **ремонт фар**: запотевание, полировка/замена стёкол, вскрытие и герметизация, треснувший корпус;
- **проблемы установки**: крепления, что ломается при вскрытии конкретной фары, ослепление/настройка.

Вне темы (отсекаем фильтром, даже если в записи мелькнёт слово «фары»): общие бортжурналы, ТО,
тюнинг кузова/салона/звука, ДХО-лампочки «на 5 минут», покупка/продажа авто, ОСАГО, ходовая.

**Фильтр темы (двухступенчатый, до любого сохранения):**
1. Положительный: заголовок/метки содержат ≥1 слово из набора линза|билед|bi-led|биксенон|би-ксенон|модуль|ретрофит|замена линз|ремонт фар|запотевани|полировка фар|стёкла фар + название авто из справочника моделей проекта (1401 модель).
2. Отрицательный: стоп-слова (продам, куплю, ОСАГО, шумоизоляция, диски, ТО…).
3. Проверка пробелами: приоритет у моделей, по которым в базе <2 независимых фактов (порог публикации `/baza/avto/…`). Остальные модели — низкий приоритет.

## 2. Что нужно взять (и сколько)

Не «весь сайт», а список **20–60 записей** под конкретные пробелы:
- ~40% — модели без страницы `/baza/avto/…` (нет 2 фактов);
- ~40% — проблемы установки на самых спрашиваемых авто (по переписке Авито: цена и «что ставим» — 84% вопросов);
- ~20% — сравнения линз (какие лучше/хуже, отзывы на конкретные SKU из каталога).

Что хранить из записи: **только факт** (авто → линза → нюанс) + ссылка на источник и ник-автор для атрибуции;
полный текст в публичную часть не идёт никогда (ст. 1270 ГК, дубли в индексе).

## 3. Каналы получения — по возрастанию риска

| Ур. | Канал | Риск | Статус |
|---|---|---|---|
| A0 | **Ручной список ссылок** от мастера + вставка текста (`run.js manual`) — ноль запросов к drive2.ru | ≈0 | нужно написать команду (1–2 ч) |
| A1 | **Web Archive / кэш** уже заархивированных записей (по своим правилам архива) | низкий | можно после A0 |
| A2 | **Yandex Search API**: `site:drive2.ru <модель> линзы` → сниппеты, индексированные с разрешения площадки | ≈0, платно | ждёт ключ (сейчас 403 — нет роли `search-api.webSearch.user`) |
| B | Точечный автозабор по готовому списку URL с обходом `Disallow: /` | **высокий, юридический + бан IP** | ⛔ только по фразе владельца «да, отключи robots-проверку для drive2, беру риск на себя» |

Мой план: A0 → A2 (когда будет ключ) → A1. B не включается без явной фразы; если владелец её даст —
действуют защиты из раздела 5.

## 4. Порядок работ

1. **Дождаться конца очереди** (≈23.09) — нельзя мерять пробелы по недособранной базе.
2. **Анализ пробелов**: SQL по `fitment` — модели с <2 фактами, топ-спрос по Авито-переписке → `seo/data/drive2-targets.csv` (модель, запрос, приоритет).
3. **Сформировать поисковые фразы**: «<модель> замена линз», «<модель> bi-led фары», «<модель> запотевают фары» — по 1–3 на модель.
4. **A2/A0**: получить ссылки (сниппеты или мастер), отфильтровать фильтром из раздела 1, положить в очередь материалов.
5. **Разбор фактов** тем же `harvest/facts.js`, `source=drive2-manual` / `drive2-snippet`.
6. **Оценка отдачи**: сколько новых моделей дошло до порога 2 фактов. Если пробелов нет — Drive2 не нужен, вопрос закрывается.

## 5. Защиты (обязательны для любого канала)

- один заход по заранее собранному списку, **не крон**; Drive2 не в общей очереди `harvest-queue.sh`;
- при первом 403/429/капче — немедленный стоп, без ретраев (чтобы не забанить IP всего RU-сервера);
- на сайт — только свои формулировки фактов, атрибуция «по материалам Drive2» со ссылкой, без ников авторов в тексте;
- сырой текст не выходит в публичную часть и в git; персональные данные не сохраняем;
- лог решения о канале — в `action_log` манифеста.

## 6. Что нужно от владельца

- выбор: идём A0+A2 (рекомендую) или нужен B (тогда — явная фраза);
- ключ Yandex Search API с ролью `search-api.webSearch.user` на папку и привязанным биллингом;
- мастер, готовый кинуть 20–40 ссылок на полезные записи (для A0).
