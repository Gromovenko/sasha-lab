# Лендинг «Фароёб»

Страница для `https://lifeprotocol.fit/faroeb`.
Исходники и все ресурсы: `mirror/sasha-lab.ru/faroeb/`. Сборка не нужна.
Основной сайт не заменяется. Node-сервер проекта отдаёт `/faroeb`, `/faroeb/`
и ресурсы `/faroeb/*`.

## Локальный просмотр

Из корня изолированного checkout:

```sh
HOST=127.0.0.1 PORT=3198 SITE_NOINDEX=1 node server.js
```

Открыть `http://127.0.0.1:3198/faroeb`.

Контроль: ширины 320, 390, 768 и 1440 px, отсутствие горизонтального скролла,
загрузка фото и шрифтов, переключатель ближнего/дальнего, раскрытие FAQ,
переход к контактам, открытие/закрытие формы записи (включая Escape),
предвыбор услуги и карусель отзывов (кнопки, клавиатура и свайп).
Переключатель света — художественная демонстрация подсветки,
не сравнение реальных характеристик фар.

## Формы и отзывы

Логотип DS «Дядя Саша» взят без изменений из оригинального зеркала:
`/cdn/static.tildacdn.com/tild6637-3766-4262-b534-616465343362/Group_28.svg`.
Локальная копия — `faroeb/assets/dyadya-sasha.svg`.

Форма в контактах и диалог записи отправляют имя, телефон, услугу, комментарий
и согласие через `POST /api/lead` в существующий движок заявок, канал `web`.
Поля имени, телефона, услуги и согласия проверяются в браузере и на сервере;
услуга и источник `/faroeb` сохраняются в тексте обращения. Успешный JSON-ответ
выдаётся после `pipeline.ingest`, разбор заявки выполняется в фоне. При ошибке
поля сохраняются для повторной попытки и показывается телефон мастерской.
Без JavaScript форма отправляется обычным POST с переходом на подтверждение.
Для реального приёма необходимо настроенное хранилище `SASHALAB_PG_URL`;
без него сервер возвращает 503, а не ложное подтверждение.

Карусель содержит короткие фрагменты трёх реальных отзывов из того же виджета,
что используется оригиналом: `https://yandex.ru/maps-reviews-widget/38789490071?comments`.
Имена сохранены, сокращения обозначены многоточиями, у каждого фрагмента есть
ссылка на отзывы мастерской в Яндекс.Картах. Тексты хранятся в HTML и автоматически
не обновляются. Автопрокрутки нет; учитывается настройка уменьшения движения.

Проверки обработчика: `node --test test/faroeb-lead.test.js` (хранилище и фоновые
действия подменены, реальные заявки не отправляются). Полный набор: `npm test`.
Браузерная проверка включает недоступность локальной БД и успешный ответ,
подменённый в браузере, без запросов в рабочую CRM.

## Подключение владельцем к lifeprotocol.fit

Выкат в рамках этой задачи не выполняется. Сервер этого репозитория сам по себе
не настраивает домен lifeprotocol.fit. Для публикации владелец может разместить
содержимое `mirror/sasha-lab.ru/faroeb/` в статическом каталоге `faroeb`
веб-сервера целевого домена. Формам дополнительно нужен тот же обработчик
`/api/lead` и доступная страница `/privacypolicy`: одной статики для приёма
заявок недостаточно. Нужно сохранить URL `/faroeb/*`, разрешить
`/faroeb/` через `index.html` и перенаправить `/faroeb` на `/faroeb/`
либо отдавать тот же HTML по обоим адресам. Если домен обслуживает приложение,
этот статический путь должен иметь приоритет перед его общим обработчиком.

После отдельной публикации проверить HTTP 200 для страницы, CSS, JS, фотографий
и шрифтов, а также превью ссылки. Canonical и Open Graph уже указывают
на `https://lifeprotocol.fit/faroeb`.

Контакты, стартовые цены и показатели мастерской взяты с публичного
https://sasha-lab.ru/. Фото работ — из локального зеркала мастерской;
герой — декоративный визуал. Цены помечены «от», окончательная стоимость
согласуется после осмотра. Внешние сервисы открываются только по ссылкам,
сторонних скриптов, аналитики и CDN-зависимостей у страницы нет.
Сборка Next.js не используется; `.next/BUILD_ID` к этому проекту не относится.
