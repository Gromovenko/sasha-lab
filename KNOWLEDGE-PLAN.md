# Своя SEO-машина: спрос по API + база знаний + ассистент

Ответ на задачу владельца от 09.09.2026. Общий план проекта — [PLAN.md](PLAN.md),
разбор поисковой стратегии — [SEO-PLAN.md](SEO-PLAN.md). Здесь: как устроен
**автоматический сбор спроса**, **база знаний из чужих источников** и **ассистент
в двух версиях**, что из этого уже работает и что нужно от владельца.

## 1. «Wordstat и Google Search Console по API — можно?»

Можно, и код для обоих уже лежит в репозитории. Важно понимать, что это **три
разных вопроса**, и отвечают на них три разных источника:

| Вопрос | Источник | Как подключено | Цена |
|---|---|---|---|
| Что люди ищут **вообще** | **Wordstat** через Yandex Cloud Search API v2 (`/v2/wordstat/topRequests`, `dynamics`, `regionsDistribution`) | `seo/lib/yandex.js` | платно, по запросам; нужен сервисный аккаунт + `folderId` |
| По каким запросам **показывают наш сайт** в Яндексе | Яндекс.Вебмастер API | `seo/lib/webmaster.js` | бесплатно, OAuth-токен |
| То же в Google | **Search Console API** (`searchAnalytics/query`) | `seo/lib/gsc.js` | бесплатно, сервисный аккаунт Google |
| Где мы **стоим** по фразе | Yandex Search API v2 (выдача) | `seo/lib/serp.js` | платно, 1 запрос/с |

Ключей на сервере пока нет — панель и команды честно говорят «нет доступа», а не
рисуют нули. Что нужно положить в `seo/.env` на RU — см. `seo/.env.example`.

### Как «изменение спроса на автомате» работает технически

Одна команда прогоняет весь цикл и пишет журнал в `job_runs`:

```
npm run seo demand      # Wordstat + Вебмастер + GSC → keywords → сео-память → intents
```

Каждый источник падает независимо: просроченный ключ Google не должен уносить
данные Вебмастера. В cron на RU это **уже стоит** (с 09.09.2026) — одной строкой вместе со сбором
источников: `0 0 * * 0 /opt/sasha-lab/scripts/harvest-cron.sh` (вс 03:00 МСК),
журнал `/var/log/sashalab-harvest.log`. Скрипт нарочно ничего не публикует:
сборка страниц и рестарт — действие человека.

Что это даёт по существу задачи («тачки меняются, Китай захватывает рынок»):
частотность **и её динамика** (`wordstatDynamics`, помесячно) снимаются
регулярно, новые модели всплывают в `keywords` сами, а `intents` каждый раз
говорит, есть ли под них страница. Не нужно догадываться, что Jolion уже стал
массовым, — это видно по цифре и по появлению модели в источниках.

## 2. База знаний: три этапа сбора

Реализованы все три, командой `npm run harvest`.

```
node harvest/run.js sources                  что за источники и что им разрешает robots.txt
node harvest/run.js crawl works              этап 1: сайты с примерами работ
node harvest/run.js crawl parts              этап 2: каталоги комплектующих
node harvest/run.js crawl community          этап 3: сообщество (hidplanet.com)
node harvest/run.js tg <канал> --pages 30    телеграм: публичное превью
node harvest/run.js tg-import result.json    телеграм: экспорт Telegram Desktop
node harvest/run.js facts                    разбор скачанного в факты
node harvest/run.js facts --reparse          пересчитать черновые факты после правки правил
node harvest/run.js stats                    что накоплено
```

Правила разбора будут правиться ещё не раз — `--reparse` сносит **черновые**
факты и разбирает документы заново; подтверждённое студией (`status='confirmed'`)
не трогается. Без этого исправленное правило не исправляет базу: документ уже
помечен разобранным, а старая ошибка живёт в `fitment` вечно (ровно так 09.09
в базе лежали «линзы q5 8r» — модели Audi, принятые за линзы, и 735 «машин»
из меню каталогов вроде «Назад Kia Carens»). После пересчёта на тех же 319
документах: 179 машин, 144 комплектующих с ценами, 283 связки.

Источники (`harvest/sources.js`) — те, что назвал владелец:
xenonshop.ru, galogenu.net, autosvet.pro, hltuning.ru (работы);
luxsar.ru, legal-xenon.ru, vdf-light.ru, criline.ru, steklafar.ru (комплектующие);
drive2.ru, телеграм-канал и **hidplanet.com** (сообщество).

### Что из этого получается: факты, а не чужие статьи

Скачанная страница попадает в `documents` — это **рабочий материал**, он не
публикуется. Разбор (`harvest/facts.js`) вынимает из него то, ради чего всё
затевалось:

- `vehicles` — марка, модель, годы (справочник строится из источников, а не
  вбивается руками: список моделей устаревает за сезон);
- `parts` — комплектующие: тип, производитель, цена, ссылка;
- `fitment` — **связка «машина → что в неё встаёт → со вскрытием или нет →
  сколько часов»**, с уверенностью и ссылкой на документ-основание.

Проверено на живых источниках: с hltuning.ru со страницы работ вынимаются
Volvo XC70, Audi A6 C7, Renault Duster, Belgee X70, Ford Kuga с указанием Aozoom;
с legal-xenon.ru — карточки переходных рамок с ценой 350 ₽ и точной машиной
(Audi A4 B5 1999–2001, Jeep Grand Cherokee 3 WK 2004–2007).

### Где проходит граница — и почему она проходит именно там

Слово «спиздить» в задаче я понимаю буквально как «забрать себе знание».
Знание забрать можно, чужой текст — нет, и это не морализаторство, а инженерное
ограничение:

- **Факты авторским правом не охраняются**, а текст — охраняется (ст. 1259, 1270 ГК).
  «В Jolion ставят Aozoom A3+ со вскрытием» — факт, его можно и нужно взять.
  Абзац с чужого сайта — нельзя.
- **Копипаста бесполезна и вредна поисково**: чужой текст уже проиндексирован у
  первоисточника, у нас он станет дублем, страница получит ноль и потянет за
  собой рейтинг раздела. То есть даже если бы это было законно, делать бы не стоило.
- Поэтому конвейер устроен так: источник → факт → **своя страница своими словами**
  со ссылкой на источник факта. Это же требование зашито в промпт ассистента.

Технические правила сбора (`harvest/http.js`) — не вежливость, а условие
живучести: robots.txt разбирается по-настоящему (шаблоны с `*` и `$`, побеждает
самое конкретное правило), пауза на источник 4–8 с, потолок страниц за заход,
честный User-Agent с адресом сайта, дисковый кэш.

### Что выяснилось про источники по ходу

- **Drive2 закрыт для сбора (проверено вечером 09.09.2026).** Утром вместо
  `robots.txt` приходил js-челлендж DDoS-Guard, и казалось, что дело в защите.
  Вечером robots отдался честно: `User-Agent: * / Disallow: /` — полный запрет
  всем, кроме поимённо разрешённых поисковиков. Обходить живой запрет — значит
  подставить студию (в User-Agent стоит адрес sasha-lab.ru, претензия идёт туда)
  и всё равно получить бан через день. Источник в реестре **выключен**, команды
  об этом говорят. Знание Drive2 берём двумя честными путями: (а) мастер кладёт
  ссылки на конкретные записи руками — в очередь материалов, такой документ
  разбирается как любой другой; (б) сниппеты по фразе через Search API — их
  Яндекс индексирует с разрешения площадки. API у Drive2 нет.
- **HIDplanet.com — добавлен 17.09.2026, берём только заголовки тем.**
  Англоязычный форум ретрофита фар: 64 тысячи тем с 2006 года, глубина, которой
  в русских источниках нет, а фара у Accord или Sonata одна на весь мир.
  Весь html форума закрыт js-челленджем Cloudflare — «Just a moment...» и 403
  на четырёх User-Agent (наш бот, браузерный, Googlebot) и на настоящем
  headless-хромиуме. Обходить защиту не стали: это ровно тот случай, из-за
  которого выключен Drive2. Но **карта сайта отдаётся свободно** (нестандартный
  адрес `/core/xmlsitemap.php`; обычный `/sitemap.xml` тоже под челленджем),
  а vBulletin печатает заголовок темы прямо в адресе:
  `60453-tsx-r-vs-black-series-clear-lens`. Заголовок площадка публикует для
  поисковиков сама — этого хватает на главный факт «в такую-то машину ставили
  такую-то линзу», и при этом в базу не попадает ни строки чужого текста.
  Отсюда режим `mode:'titles'` в `harvest/crawl.js`: страницы не качаются вообще,
  документ рождается из адреса. Из 55 199 тем разрешённых разделов (маркетплейс
  и офтоп не берём) зацепку дают **8 920**, из них разбор вынимает около 1 200
  машин и 240 связок «машина → линза»: Accord, Civic, E46, TL, A4, Sonata
  с Morimoto, ZKW, Hella, Bosch. robots площадки (17.09.2026) нашему UA
  раздел «*» разрешает, `Crawl-delay: 10` соблюдается; отдельно там закрыты
  GPTBot, CCBot и Google-Extended — площадка против обучения моделей на её
  обсуждениях, поэтому текста мы и не берём. Попросят убрать — источник
  выключается одной строкой, как Drive2.
- **Английский источник потребовал правок разбора.** «mini h1» на таком форуме —
  это линза Morimoto Mini, а не BMW Mini; «hyundai sonata clear lens upgrade»
  давал машину «Sonata Clear Lens». Поэтому в `harvest/vehicles.js` появились
  английские стоп-слова, цоколи ламп (`h1`, `d2s`…) как не-модели, список
  неоднозначных марок (`mini`, `seat`, `smart`, `tank`) и правило «у английского
  заголовка хвост модели — только поколение или комплектация». Имена линз
  переехали в `harvest/lenses.js`: список нужен и разбору фактов, и разбору
  машин («Honda Insight Morimoto» — не модель «Insight Morimoto»).
- **Телеграм.** Публичное превью `t.me/s/<канал>` отдаёт посты без бота и без
  аккаунта (проверено), но **не отдаёт комментарии** — а в канале про ремонт фар
  половина ценности именно в обсуждении. Поэтому первый заход правильно делать
  экспортом из Telegram Desktop (`tg-import`), дальше догонять через превью.
  **От владельца нужно: имя канала** (в задаче он не назван) — а если канал
  закрытый, то файл экспорта.
- **Sitemap есть почти у всех** (hltuning — 942 адреса, legal-xenon — 3491), так
  что обход идёт по осмысленным страницам, а не по фильтрам каталога.

## 3. Редакционная модель вместо форума (пункт 2 задачи)

Уже работает: форма «спросить мастера» на сайте → очередь в панели → ответ студии
→ материал базы знаний. Вопросы реальные, ответ подписан студией. Почему не форум
с выдуманными пользователями — разобрано в SEO-PLAN.md, раздел 1.2 (ручная санкция
Google за scaled content abuse прилетает на **весь домен**, а не на раздел).

## 4. Статические страницы по машинам (пункт 3)

`/baza/avto/<марка-модель>/` собираются из `fitment` при сборке статики.
**Порог намеренный:** страница появляется, только если по машине есть либо факт,
подтверждённый студией, либо два независимых факта (`MIN_FACTS` в `content/build.js`).
Машина, упомянутая в источниках один раз, страницы не получает — тысяча пустых
страниц «линзы в <модель>» это и есть дорвейная сетка, за которую санкция.

## 5. Сео-память (пункт 4)

`seo/lib/memory.js` + таблица `intents`. Фраза нормализуется (стоп-слова, обрезка
окончаний, словарь синонимов: «потеют» = «запотевание» = «конденсат»), после чего
принимается **одно** решение и запоминается:

- `covered` — за фразу уже отвечает существующая страница, делать нечего;
- `strengthen` — близкий интент: дописать в существующую страницу и усилить её;
- `new` — самостоятельный интент, заслуживает своего адреса;
- `skip` — мусор.

Решение владельца (`decided_by = 'owner'`) пересчётом не перетирается.
Смотреть очередь: `npm run seo queue` — отдельно «что писать» и «что усилить».

## 6. Ассистент базы знаний в двух версиях (h3 из задачи)

Страница `/baza/pomoshnik/`, ручки `POST /baza/assistant` и `GET /baza/podbor`.

- **Владелец машины** — человеческий ответ по материалам студии, без каталожных
  номеров, всегда с дверью к живому мастеру.
- **Установщик** — марка/модель/год → таблица «что встаёт, со вскрытием или нет,
  сколько часов, уверенность» + комплектующие с ценами и ссылками. Ровно то,
  что просил владелец: «забил марку-модель-год, выкатило все данные».

Три правила, на которых он держится:

1. Отвечает **только** по базе. Нет факта — говорит «в базе нет» и зовёт мастера.
   Придуманный совет по чужой фаре стоит клиенту оптики, поэтому «додумать по
   аналогии с соседним поколением» ассистенту прямо запрещено промптом.
2. Каждый ответ несёт источники: материал базы знаний, ссылку на документ.
3. Вопрос, на который ответа не нашлось, помечается `unanswered` и попадает в
   очередь студии. **Это бесплатный поставщик тем**: спрашивают ровно то, чего
   базе не хватает.

Модель — Qwen на neuraldeep (GPU в РФ, вопросы посетителей не уезжают за периметр,
152-ФЗ). Без ключа ассистент не падает и не выдумывает: отвечает выдержками из
базы знаний — проверено на живом сервере.

## 7. Что нужно от владельца

1. **Ключи** (`seo/.env` на RU): Yandex Cloud (Wordstat + Search API), OAuth
   Вебмастера, сервисный аккаунт GSC, `NEURALDEEP_API_KEY` для ассистента.
   Без первых трёх «автомат по спросу» считает по пустым данным.
2. **Имя телеграм-канала** или файл экспорта — в задаче канал не назван.
3. **Подтверждение фактов.** Самое ценное, что может дать студия: пройти по
   `fitment` и пометить проверенное (`status='confirmed'`). Факт, подтверждённый
   мастером, — это то, чего нет ни у одного конкурента; собранное из источников
   без подтверждения остаётся «по данным открытых источников».
4. **Решение по домену** (шаг 0 в PLAN.md) — пока оно не принято, вся эта машина
   работает «в стол» под `noindex`.

## 8. Чего эта система не делает

Не генерирует страницы пачками под ключи, не пишет отзывы и вопросы «от лица
пользователей», не публикует чужой текст и не переписывает чужие статьи «под
уникальность». Всё это — известные способы получить санкцию на домен целиком,
и ни один из них не окупает риска для студии, живущей с локального трафика.
